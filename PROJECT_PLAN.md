# Student Records System — Project Plan

## Project Overview
A simple web application for managing student records, built with Vanilla JavaScript, Vite, and Supabase.

## Features
- Operator sign in / sign up
- Add, edit, and delete student records
- Search student list
- Course dropdown from database
- Count students per course

## Technologies Used
- HTML5
- Vanilla JavaScript
- CSS
- Vite
- Supabase (Auth + Database)

## Project Structure
- `src/` — main JavaScript, styles, and Supabase client
- `database/` — SQL setup files
- `documentation/` — project notes
